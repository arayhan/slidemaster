# SlideMaster

Scaffolded with `create-project`. Stack: TanStack Start, TypeScript, pnpm.

Read [AGENTS.md](AGENTS.md) first — it points at everything else. (`CLAUDE.md` is a two-line pointer to it, for Claude Code.) The coding rules are in [`docs/rules/`](docs/rules/).

## Install & run

```bash
pnpm install
cp .env.example .env
pnpm dev
```
